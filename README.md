#  Sobre o projeto

Este projeto foi desenvolvido como parte do Checkpoint 2 da disciplina de programação, utilizando a biblioteca Pygame em Python.

O objetivo do trabalho foi criar um jogo digital funcional, aplicando conceitos de:
- lógica de programação;
- movimentação;
- colisões;
- eventos;
- estados do jogo;
- organização de código;
- criatividade no desenvolvimento.

O jogo desenvolvido pelo grupo é um jogo de plataforma chamado **Transformouse**, inspirado em jogos como Transformice.

No jogo, o jogador controla um rato que deve:
1. atravessar plataformas;
2. evitar armadilhas;
3. coletar o queijo;
4. chegar até a toca para avançar de fase.

O projeto possui:
- tela inicial;
- sistema de fases;
- pontuação;
- partículas;
- condição de vitória;
- movimentação e pulo;
- colisões;
- interface gráfica utilizando Pygame.

#  Instruções de execução

##  Pré-requisitos

Ter instalado:
- Python 3.10 ou superior

---

##  Instalação das dependências

Abra o terminal na pasta do projeto e execute:

```bash
pip install -r requirements.txt
```

---

## ✅ Executar o jogo

Após instalar as dependências, execute:

```bash
python main.py
```
